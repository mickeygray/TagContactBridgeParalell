# Speaker Label Call Script

Read these lines in order. For native diarize, use two real voices if possible. If one person is reading both sides, use a natural but clearly different cadence and leave a short pause between turns.

**Prospect:** Hello, this is Mickey Gray. I am answering the phone and trying to figure out who is calling.

**Agent:** Hi Mickey, this is Alex with Tax Advocate Group. I am calling about the tax help request we received, and I want to make sure you can hear me clearly before I ask anything important.

**Prospect:** Yes, I can hear you. I got a letter in the mail last week, and I am not sure if it means I owe money right now or if it is just a warning.

**Agent:** Okay, that makes sense. The first thing I need to understand is whether the main issue is a balance, unfiled returns, or both, because that changes what the consultant should review.

**Prospect:** I filed the last two years, but I still owe for twenty twenty two. I was making payments for a while, then I stopped because the amount did not seem to be going down.

**Agent:** Got it. A consultant can review the basics with you by phone, look at the notice type, and explain what the next practical step should be without guessing over text.
